## 五、这段演示证明了什么

1. **判定前移**：契约在动手之前写定，模型只能按契约产出，看不到"标准松紧"的余地。
2. **判定唯一**：交付是否成立只由四类闸门决定；模型自评与复核意见都不参与。
3. **过程可查**：一条 `run_id` 串起四次事件（启动、调用、判定、结束），
   任何一次交付都能回答"哪个任务、哪个模型、哪一版契约、为什么通过"。
4. **契约版本可核对**：`contract_hash = 9aaf78c2f5cca6b0`。用当前契约复算得到同一个值——
   该指纹已去掉 `repo` 绝对路径，同一份契约放在任何目录下都一致。
5. **可复现**：同一命令在本机可重跑；历史逐次记录见 `experiments/附件/`。

> 说明：`contract_hash` 是 2026-11-28 才写入审计的；更早的历史运行没有记录，
> 在 `experiments/附件/逐次结果.csv` 中一律标为「缺失」。
