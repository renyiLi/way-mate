# 环境约定（本机固定规则）

> 目的：避免每次新会话重新踩 Windows 上 PowerShell 版本、编码、路径风格的老坑。

## 1. PowerShell 版本

本机装有 **PowerShell 7.7.0（Core）**，且**已在用户 PATH 中**。

但注意：`ops_bash`（MSYS Bash）的 PATH 经沙箱裁剪，**不含该目录**，所以在 bash 里 `which pwsh` 会找不到——这不是系统 PATH 的问题。

```
C:\\Users\\23812\\AppData\\Local\\Programs\\PowerShell\\7.7.0\\pwsh.exe
```

调用约定：

| 场景 | 用什么 |
|---|---|
| 默认（脚本、系统信息、HTTP、注册表） | 上面的 pwsh 7 绝对路径 |
| 碰到 7 不兼容的老 cmdlet / 参数 | 回退 `powershell.exe`（5.1.26100.9818） |

固定参数：`-NoProfile -NonInteractive`（避免加载用户配置、避免卡在提示符）。

## 2. 三条纪律

1. **强制 UTF-8 输出**：PowerShell 每段脚本开头加
   `[Console]::OutputEncoding=[Text.Encoding]::UTF8`，否则中文经管道会乱码。
2. **不猜命令存在**：先 `Get-Command xxx -ErrorAction SilentlyContinue` 再调用。
3. **不碰交互**：任何会弹 UAC / 需要确认的命令，改成非交互形式或直接报告。

## 3. 已知的 5.1 与 7 差异（踩过的坑）

| 现象 | 5.1 的问题 | 7 的行为 |
|---|---|---|
| `Invoke-WebRequest` 取文本 | 缺 `-UseBasicParsing` 会报"非交互模式"错 | 不再需要该参数 |
| 写文件 | `-Encoding UTF8` 会带 BOM | 默认无 BOM |
| `Invoke-RestMethod` 报错信息 | 结构与 7 不同 | 更接近 .NET 异常 |
| 并行、`ForEach-Object -Parallel` | 无 | 有 |

## 4. 两种 shell 的分工

本会话的 `ops_bash` 是 **MSYS Bash**（不是 WSL，也不是 PowerShell）。

| 任务 | 用哪个 |
|---|---|
| 文件读写、git、python、pytest、ruff | Bash（路径写 `/e/随行工作台` 风格） |
| Windows 系统操作、注册表、COM、服务 | pwsh 7 绝对路径（路径写 `E:\随行工作台` 风格） |
| 大段文本写入 | Bash heredoc（`cat > f <<'EOF'`），避免 PowerShell 转义地狱 |

注意：Bash 里引用 Windows 路径要加引号，`C:\...` 中的反斜杠在双引号内会被吃掉。

## 5. git 用哪一份（重要）

`ops_bash` 里的 `git` 是 DSH 沙箱自带的一份：

```
C:\\Users\\23812\\.dsh\\dsh-ops\\shells\\niubash-prepared\\<hash>\winuxcmd\opt\niugit\mingw64\bin\git.exe
```

它**读不到系统级凭据配置**（`credential.helper` 为空），所以 `git push` 会直接报
`could not read Password for 'https://...'`。

**推送、拉私有库一律用用户自己的 Git：**

```
/e/Git/cmd/git.exe          # 2.56.0.windows.4，credential.helper = manager（可用）
```

只读操作（`clone`、`diff`、`log`、`status`）用哪一份都行。

## 7. 不要生成保留设备名文件

`> CON` / `> AUX` / `> NUL` 这类重定向会在工作区留下名为 `CON`、`AUX` 的文件，
`git add -A` 会直接失败（`unable to index file 'CON'`），而且 `cat` 它会挂起等输入。

删除方式（必须用扩展路径前缀，否则 PowerShell 会当成设备）：

```powershell
Remove-Item -LiteralPath '\\?\E:\随行工作台\CON' -Force
```

## 8. 在 ops_bash 里调用 pwsh

沙箱 bash 的 PATH 不含 PowerShell 目录，先补一行再调用：

```bash
export PATH="$PATH:/c/Users/23812/AppData/Local/Programs/PowerShell/7.7.0"
pwsh -NoProfile -NonInteractive -Command '$PSVersionTable.PSVersion.ToString()'
```

或者直接用绝对路径（更省事，不受 PATH 影响）：

```bash
/c/Users/23812/AppData/Local/Programs/PowerShell/7.7.0/pwsh.exe -NoProfile -Command '...'
```
