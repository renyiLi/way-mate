04规则

不做的事，写在规范里

动效只有两档：L1 精致静态（hover、折叠、切换，160–220ms），加一处 L2——首屏判定板逐项判定后盖章。所有动效在 prefers-reduced-motion 下直接出结果。

  1. 不用近黑底 + 荧光绿 / 荧光橙
  2. 不用米黄 + 高对比衬线 + 陶土色的组合
  3. 不把内容切成等大圆角卡片网格，不用同一层软阴影
  4. 不在标题里给单个词换色、换斜体
  5. 不给每张卡加 fade-and-slide-up 入场
  6. 不用 emoji 当图标，不在按钮后面缀箭头
  7. 黄、红、绿三色不复用于装饰

完整规范在 web/DESIGN.md：色板、字体、版式、动效档位、性能红线和全部 Don'ts。

样式是判定的一部分。

页面用同一套 token 渲染四类闸门与交付记录。判定逻辑在 Python 里，视觉只负责让"过没过"一眼看清。
