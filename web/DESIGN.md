# 外壳设计规范 · 随行交付台

> 参照 `anthropics/skills` 的 `frontend-design`（反模板味、只花一次胆量）与
> `KAOPU-XiaoPu/web-design`（先出规范再写码、性能红线、中文字排规则）写成。
> 这份文件只服务 `web/` 这一个壳，不改变 `src/dbw` 的任何判定。

## 1. 视觉母题

**车间验收台。** 主题世界里的实物是：验收单、闸门栏杆、警示胶带、检验印章、竣工章。
页面不是"AI 控制台"，而是一张摆在台面上的检验单：纸面、硬边、编号条款、盖章生效。

一句话定调：**像一份能盖章的文件，而不是一个能刷新的 dashboard。**

## 2. 颜色

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#E8E9E2` | 台面纸色（偏冷灰绿，不是米黄） |
| `--sheet` | `#F4F4EE` | 抬起的面板（判定板 / 卡片） |
| `--ink` | `#15170F` | 正文与硬边框（带绿倾向的黑） |
| `--ink-2` | `#3A3E33` | 次级正文 |
| `--muted` | `#6C7064` | 注释、字段名 |
| `--rule` | `#C8CABE` | 分隔线 |
| `--hazard` | `#E0B418` | 安全黄：进行中、警示胶带、要点左侧竖条 |
| `--seal` | `#A82C1B` | 朱砂：驳回、印章 |
| `--pass` | `#2A5A43` | 通过 |

规则：**黄色只做块面（胶带、竖条、进行中），不写小字**；朱砂只给"驳回 / 印章"；绿色只给"通过"。
三类颜色各自只有一个含义，跨页面不允许复用。

## 3. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 显示 / 数字 | `Archivo`（自托管，`assets/fonts/`） | 拉丁与数字用 800/600，中文回落系统黑体 |
| 正文 | 系统黑体栈（`PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`） | 中文字形不硬造，靠字重与字号建立层级 |
| 数据 | `IBM Plex Mono`（自托管） | 只给真正的机器值：exit code、token、文件名、闸门代号 |

中文排版：行高 ≥ 1.7，字距 `.01em`，正文 16px，标题字距收紧到 `-.02em`。
**不做的**：全大写小标签、章节上方的 tracked-out eyebrow、句中单词染色、`→` 后缀。

## 4. 版式

```
┌ topbar ─────────────────────────────── 吸附，1px 墨线 ──┐
│ 验 随行交付台  v0.2      主张 任务 闸门 记录  只读快照 │
├─────────────────────────────────────────────────────────┤
│ 第 1 条 · 主张              ┌──────────────────────────┐ │
│ 模型可以争论，               │ 判定板   [回放]           │ │
│ 闸门说了算。                 │ tabulate-362  11-25 14:04 │ │
│                              │ tests ● 1 failed          │ │
│ [看运行记录] [读任务与契约]   │ ...                       │ │
│ 2 / 53 / 30 / 44             │ 1 项未通过      [不予交付] │ │
├════ 警示胶带 12px，全页仅此一处 ═════════════════════════┤
│ 第 2 条 · 任务   tasks/*/task.json → 两张任务卡 + 契约原文 │
│ 第 3 条 · 闸门   四张判定卡 + 真实判定次数/失败次数        │
│ 第 4 条 · 记录   audit.jsonl 聚合 → 可展开的运行表         │
├ footer ─ 反色墨块：契约不可替换 + 数据来源 ──────────────┤
```

条款编号（第 N 条）是真编号——内容本来就是契约条款，不是装饰。
桌面端左栏 132px 固定放条款号，正文右栏；≤ 980px 折为单列。

## 4.1 视图骨架

概览之外有四层视图，共用同一套骨架（左栏条款标签 + 右栏正文），不另起设计语言：

| 视图 | 左栏标签 | 结构 |
|---|---|---|
| 任务列表 | `tasks` | 任务卡网格 |
| 任务详情 | `task` | 面包屑 → 标题 → 契约字段表 → 该任务的运行表 |
| 运行列表 | `runs` | 结果筛选条 → 运行表 |
| 运行详情 | `run` | 面包屑 → 元信息表 → 闸门逐项 → 事件时间线 |

面包屑只出现在详情页；列表页靠顶部导航指示位置，避免「任务 / 任务」重复。
两张"数据表"用同一种行样式：左侧 mono 键、右侧值，行间 1px 线，不加底色交替。

## 5. 组件

- **按钮**：3px 圆角，实心墨色 / 描边两种；hover 上移 1px + 硬投影 `4px 4px 0`；`focus-visible` 2px 外描边。
- **判定行**：`灯 · 代号 · 判什么 · 实测值`；灯 8px 圆点，四态 `idle / running / pass / fail`。
- **判定详情行**：`.gate-line`，`灯 · 代号 · 值`在首行、`detail` 原文另起一行（12px 灰），用于运行详情页。
- **时间线**：`.timeline`，`时间（mono 11.5）· 事件名（mono 11.5）· 摘要`；失败事件的事件名转朱砂。窄屏把摘要折到下一行。
- **对比表**：`.compare-table`，差异行用安全黄 12% 底纹，"差异"列用黄底 mono 小标。**不用红/绿表示"不同"**——红绿在这个系统里已经被"驳回/通过"占了，混用会让读者误判。
- **印章**：88px 方章，双线边框，`rotate(-7deg)`，落下时 `scale(1.3)→1`，只落一次。
- **阴影**：只用无模糊硬投影（`6px 6px 0 rgba(21,23,15,.10)`），不用 `0 4px 20px rgba(0,0,0,.1)` 那种软阴影。
- **圆角**：统一 2–3px，不做胶囊、不做 16px 大圆角。

## 6. 动效档位：L1 精致静态 + 一个 L2 时刻

- 只有一处编排动效：**首屏判定板按记录回放最近一次运行 → 盖章**（加载 650ms 后自动放一次，点「回放」可重放）。数据是真实运行结果，动效只是复现它的判定顺序。
- 其余全部是回答式反馈：hover、折叠、排班切换、展开运行表，时长 160–220ms。
- `prefers-reduced-motion: reduce` 时：跳过序列，直接出结果，印章不做缩放。

## 6.1 打印

纸上只有"证据"，没有"壳"：隐藏顶栏、页脚、胶带、筛选、面包屑和条款标签，留判定板、闸门逐项、事件时间线。

- A4，14/12mm 页边距；正文 10.5pt，表格 9.5pt
- 颜色必须能打出来：灯、色条、印章加 `print-color-adjust: exact`，否则打印成空白格
- 行级容器一律 `break-inside: avoid`；标题 `break-after: avoid`
- 详情页有一行只在纸上出现的页眉：对象 id + 数据快照时间 + 数据源

## 7. 性能红线（自检）

- 零第三方 JS，零构建，零 CDN（字体已自托管，共 228 KB）。
- 不使用 `filter: blur()`、无 WebGL、无 `backdrop-filter` 覆盖滚动区（仅 topbar 10px）。
- 监听仅在 `pointer`/`scroll` 上做 passive + `IntersectionObserver`，无 `pointermove` 长跑。

## 8. Don'ts

1. 不用近黑底 + 荧光绿 / 荧光橙；
2. 不用米黄 + 高对比衬线 + 陶土色的组合；
3. 不把内容切成等大圆角卡片网格，不用同一层软阴影；
4. 不在标题里给单个词换色、换斜体；
5. 不给每张卡加 fade-and-slide-up 入场；
6. 不用 `A · B · C` 式元信息串、不用 `WORD — 片段` 式标签；
7. 不引入 emoji 当图标；
8. 黄、红、绿三色不复用于装饰。
