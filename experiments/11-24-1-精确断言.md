# 11/24/1 · 精确断言对通过率与成本的影响

**日期**：2026-11-24（Asia/Shanghai）
**脚本**：`scripts/experiment_exact.py`
**任务**：`fixtures/repo_a`（示例仓库 `fix-parser-inline-comment`，5 条 pytest）

## 目的

验证把"测试里隐含的逐字要求"提进契约（`exact` 字段）之后：

- 预期 A：原本失败的模型能被救回；
- 预期 B：token 与耗时下降（模型不再需要猜该写什么）。

## 设置

| 项 | 值 |
|---|---|
| 变量 | 契约副本里**有无 `exact` 段**，其余全同 |
| 模型 | `deepseek/deepseek-chat`、`ark/deepseek-v4-1-flash-261017`、`ark/kimi-k3-1-pro-261024`、`ark/doubao-seed-2-1-pro-260915` |
| 每格次数 | 首轮 1 次；第二轮 3 次（doubao 因单次约 118s，仅 1 次） |
| 判定 | 四类闸门全绿才算通过 |

## 结果

### 首轮（n=1）—— 后来被证伪

无 `exact` 1/4 → 有 `exact` 4/4，当时判为"四组结果与是否写明精确字符串完全相关"。

### 第二轮（n=3）

| 模型 | 无 exact | 有 exact | 平均 token | 平均耗时 |
|---|---|---|---|---|
| `deepseek-chat` | **0/3** | **3/3** | 999 → 1046 | 1.8s → 2.3s |
| `deepseek-v4-1-flash` | 3/3 | 3/3 | 2207 → 2030（−8%） | 8.3s → 6.3s |
| `kimi-k3-1-pro` | 3/3 | 3/3 | 5513 → **2308（−58%）** | 110.4s → **46.0s** |

合计 6/9 → 9/9。（`doubao` 首轮 n=1：无 exact 失败、有 exact 通过，样本不足未计入。）

## 结论

- **救回效应成立**：`deepseek-chat` 三次全败变三次全胜，效应稳定。
- **成本效应成立但只在一个模型上明显**：`kimi` 结果不变而 token、耗时各降约 58%，说明它原本在"猜该满足什么"。
- **天花效应**：`flash` 两条件均满分，此任务对已饱和的模型无法区分条件。

## 局限

1. 单条任务、单一难度，天花板吞掉了两个模型的条件差异；
2. `doubao` 样本不足；
3. 首轮 n=1 的强结论被第二轮推翻——**这是本实验最重要的教训**。

## 复现

```powershell
python scripts/experiment_exact.py --fresh --reps 3
```

明细写入 `runs/experiment-exact-<时间戳>.json`（不入库）。
